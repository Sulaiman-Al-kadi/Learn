## Hint 1
A tab inside a string is written as `\t`. So `"Item:\tLatte"` prints `Item:`, a tab, then `Latte`.

## Hint 2
`Console.Write("Total:\t");` prints without moving to a new line. Then `Console.WriteLine(15 * 2);` — no quotes! — prints `30` on that same line and ends it.

## Hint 3
To put a `"` inside a string, write `\"`. To print a backslash, either double it (`\`) or put `@` before the opening quote: `@"C:\shop\receipts"`.
