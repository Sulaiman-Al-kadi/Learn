# Exercise — Exam statistics

Summarize exam results.

1. `AverageBySubject`: a dictionary of subject to average score.
2. `TopScorer`: the student with the highest score, or `null` for an empty list.
3. `EveryonePassed`: true when every score is at least `passMark`. An empty list counts as true.
4. `NamesPage`: student names A to Z, then one page of them. `page` starts at 1.
